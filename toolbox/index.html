Year 9 Metalwork

Sheet-metal Toolbox

This unit keeps the brief, drawing, workshop controls, production theory and evidence together across five two-week modules.

How the unit works

A predictable routine for each module

Use the same four steps from the first source check to the saved evidence.

1. Read

Use the theory, brief and teacher-issued drawing for the current stage.

2. Practise

Complete the knowledge checks and use the feedback.

3. Apply

Connect the theory to teacher-supervised Toolbox production.

4. Save

Keep written explanations and folio evidence, then save a PDF backup.

Student evidence. Work autosaves in this browser and is not submitted automatically.
